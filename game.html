About Us

Prisma Worlds — portal jelajah 3D

Prisma Worlds lahir dari ide sederhana: berjalan-jalan pun bisa jadi permainan. Kami membangun tiga dunia dengan Three.js — penuh sudut untuk dijelajahi dan landmark kecil untuk ditemukan. Tidak ada skor, tidak ada game over. Masuk lewat gerbang mana pun, kelilingi sesukamu, dan pulang kapan saja kau mau.

Tiga Dunia Kami — ketuk untuk masuk

— Tim Prisma · tiga orang, satu kanvas, terlalu banyak kopi.

Kontrol — Mouse & Keyboard
mouseGerakkan mouse untuk melihat sekeliling — klik layar untuk mengunci kursor.
keyboardW A S D atau panah untuk berjalan, Shift untuk berlari, Spasi untuk melompat.
pauseTekan Esc kapan saja untuk menjeda atau melanjutkan.
Kontrol — Sentuh
gamepadJoystick kiri untuk berjalan — dorong sampai penuh untuk berlari.
swipeGeser layar (area mana pun selain joystick) untuk melihat sekeliling.
arrow_upwardTombol panah di kanan bawah untuk melompat.
